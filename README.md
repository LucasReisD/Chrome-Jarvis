## 📖 Sobre o Projeto

O **JARVIS** é uma extensão para o Google Chrome projetada para trazer automação, produtividade e recursos de Inteligência Artificial direto para a sua navegação do dia a dia. Inspirado no assistente do Homem de Ferro, ele foi construído utilizando as tecnologias web mais recentes e padrões modernos de extensões.

---

## ✨ Funcionalidades

- **Acesso Rápido:** Interface leve e responsiva direto no popup da extensão.
- **Automação de Páginas:** Interações inteligentes com o conteúdo das abas ativas (Content Scripts).
- **Processamento em Segundo Plano:** Gerenciamento de eventos e requisições via Service Workers (Manifest V3).
- **Integração com IA:** Respostas e assistência contextualizadas enquanto você navega.

---

## 🛠️ Tecnologias Utilizadas

- **JavaScript (ES6+)** — Lógica principal da extensão.
- **HTML5 & CSS3** — Interface de usuário (Popup e Options).
- **Chrome Extensions API (Manifest V3)** — Arquitetura padrão moderna do Chrome.
